# DEAD COUNTY

Jogo de sobrevivência zumbi em pixel art, executado diretamente no navegador.

## Como jogar

Abra `index.html` ou inicie `python3 -m http.server 8080`. Use WASD para mover, Shift para correr, Espaço ou clique para atacar, E para vasculhar, R para recarregar, I para inventário, C para fabricar, 1/2/3 para equipamentos, Q para curar e Esc para pausar. Há controles por toque para dispositivos móveis.

## Sistemas

- Mundo gerado deterministicamente, cache LRU de chunks, sprites pixel art por Canvas 2D.
- Zumbis comuns e corredores, armas, inventário, loot e crafting.
- Fome, sede, infecção, estamina, saúde, chuva, ciclo dia-noite e salvamento local.
- Missão: reunir circuitos, combustível e sucata, ativar torre e sobreviver à defesa.

Projeto original independente, inspirado no gênero survival, sem afiliação com Project Zomboid. Protótipo jogável de escopo indie, não um jogo AAA comercial completo.
